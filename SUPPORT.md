# Support — Italian Investor

For bugs, reproducible calculation issues, documentation problems, or feature requests, open a GitHub issue:

https://github.com/eliazv/italian-investor/issues

When reporting a calculation or tax-rule issue, include only the minimum data needed to reproduce it. Do not post account credentials, API keys, tax IDs, brokerage login details, private statements, or other sensitive personal information in a public issue.

For tax-law or instrument-classification reports, include the authoritative source (for example Normattiva, Agenzia delle Entrate, MEF, CONSOB, EUR-Lex/ESMA, KID, prospectus, issuer, or broker documentation) and the date/version that supports the report.

Italian Investor is an open-source analysis and simulation project. Support does not constitute personalized financial, investment, legal, or tax advice.
