# Privacy Policy — Italian Investor

Last updated: 28 August 2026

Italian Investor is an open-source, skills-only plugin and Agent Skill for portfolio analysis and Italian tax-aware simulations.

## Data handled by the developer

Italian Investor does not operate a developer-controlled backend, account system, analytics service, advertising system, or remote database. The bundled Python scripts perform local/deterministic calculations and do not send portfolio data to the developer.

The developer does not receive, store, sell, or use the portfolio files, prompts, tax information, broker information, or other content that a user provides to the host AI product merely because the user invokes Italian Investor.

## Host platform processing

When Italian Investor is used inside ChatGPT, Codex, Claude, or another compatible host, prompts, uploaded files, generated outputs, and execution data may be processed by that host according to its own terms and privacy policy. That processing is outside the control of this project.

## External sources

The skill may instruct the host to consult authoritative third-party sources such as Normattiva, Agenzia delle Entrate, MEF, CONSOB, EUR-Lex, ESMA, issuers, brokers, KIDs, or prospectuses. Access to those external services is subject to their own privacy policies and terms.

## Repository and support

If you voluntarily open a GitHub issue, discussion, pull request, or otherwise contact the developer, the information you submit is handled through the service you chose to use and may be publicly visible depending on that service and your settings.

## Changes

This policy may be updated when the plugin architecture or data handling changes. Material changes will be reflected in this file and in the repository history.
